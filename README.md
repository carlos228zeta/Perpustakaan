# Perpustakaan
Sistem Perpustakaan Sekolah berbasis web untuk mengelola data buku, anggota, peminjaman, pengembalian, dan riwayat transaksi secara digital. Dikembangkan sebagai proyek sistem informasi untuk membantu meningkatkan efisiensi dan kemudahan pengelolaan perpustakaan di Sekolah Cinta Kasih Tzu Chi Cengkareng.
